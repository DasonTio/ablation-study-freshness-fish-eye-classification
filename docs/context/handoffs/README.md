# Handoff Notes

Create a dated handoff note in this directory only when the project crosses a major phase boundary or pauses after a meaningful milestone.

Examples:

- research framing to experiment design
- design approval to implementation
- implementation milestone reached with unresolved blockers

Do not create a new handoff file for routine small updates. Use `docs/context/current.md` for the latest state and `docs/context/decisions.md` for durable rationale.
